Software de Astronomía

💻 Herramientas digitales para planificar observaciones, simular el cielo y procesar imágenes. Todos los enlaces directos a sus sitios oficiales.

🌟

Stellarium

Planetario gratuito en 3D. Simulación del cielo, catálogos de estrellas y nebulosas. Ideal para planificar.

🖥️ Win / Mac / Linux 📱 iOS / Android
🔗 Visitar web
📊

Cartes du Ciel

Planisferio digital con control de telescopio. Permite cargar catálogos extensos y cartas detalladas.

🖥️ Win / Mac / Linux
🔗 Visitar web
🚀

SkySafari

Millones de objetos, control GoTo y realidad aumentada. Versión móvil y de escritorio.

📱 iOS / Android 🖥️ Mac / Win
🔗 Visitar web
🖼️

DeepSkyStacker

Apilado de imágenes para astrofotografía. Reduce ruido y mejora la señal en cielo profundo.

🖥️ Windows
🔗 Visitar web
🎯

PHD2 Guiding

Guiado automático para astrofotografía. Mantiene estrellas fijas en exposiciones largas.

🖥️ Win / Mac / Linux
🔗 Visitar web
🔌

ASCOM Platform

Estándar para comunicación entre software y hardware astronómico (telescopios, cámaras, filtros).

🖥️ Windows
🔗 Visitar web
🌌

KStars

Planetario de código abierto con control de telescopio y EKOS para astrofotografía automatizada.

🖥️ Linux / Mac / Win 📱 Android
🔗 Visitar web
🔍

Astrometry.net

Resuelve automáticamente la orientación y coordenadas de tus imágenes astronómicas (plate solving).

🌐 Web / API 🖥️ Linux / Mac / Win
🔗 Visitar web

📌 Todos los programas son de uso gratuito o con versiones de prueba. Algunos requieren registro para funcionalidades avanzadas.
